# Roadmap

## Next iteration

- Test the page with keyboard-only navigation and common screen readers.
- Validate the color system with automated and manual contrast checks.
- Test the five primary leasing tasks with representative users.
- Connect the search controls to realistic filtered results.
- Add clear empty, loading, validation, and error states.

## Future development

- Extract the header, offer, search form, benefits, and footer into reusable components if the project expands beyond one page.
- Add vehicle-listing and offer-detail templates.
- Introduce documented design tokens for color, typography, spacing, elevation, and motion.
- Add automated HTML, accessibility, and responsive visual checks.
- Optimize source images and add responsive image variants.

## Content guidelines

- Keep leasing terms together and written in plain language.
- Use visible labels instead of placeholder-only instructions.
- Distinguish implemented behavior from future concepts.
- Do not claim validated outcomes until testing is completed.
